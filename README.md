# 30 Days of C

30 original AI-assisted C17 learning examples, republished one per day from **31 October to 29 November 2026**, scheduled for **9:07 AM IST**. GitHub Actions may run later than the scheduled time.

The earlier complete collection is preserved in [lesson-bank](lesson-bank). Daily publications appear in programs below. Existing Git history is preserved.
