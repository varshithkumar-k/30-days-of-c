# 30 Days of C

30 beginner-friendly, original AI-assisted C17 examples. One lesson is published per day from **29 October to 27 November 2026**.

The daily workflow targets **7:30 PM India time** (14:00 UTC); GitHub may delay scheduled runs. The first lesson is published during setup. All 30 examples were compiled with strict warnings and their sample outputs checked before scheduling. Each published lesson is tested again.

## Originality

Code and explanations were newly generated for this project, without copying third-party repositories, tutorials or paid course material. These are common programming exercises; similar implementations can exist. No exhaustive copyright or similarity clearance is claimed. AI assistance is disclosed.

## Learning path

Basics, conditions, loops, number algorithms, arrays, sorting, strings, pointers, structs, dynamic allocation, file handling, bit flags, stacks and small study projects.

## Scheduling

The workflow stores the prepared lesson queue and publishes at most one missing eligible lesson per run. Re-running on the same day is idempotent. After all 30 lessons are published, no new lesson is created. A manual workflow run can recover a missed day.
