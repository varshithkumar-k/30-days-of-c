# Day 30: Study Planner

Mini project: summarize completed sessions and remaining minutes.

This example uses fixed sample data. Change the values to practice.

## Run

```sh
gcc -std=c17 -Wall -Wextra -pedantic main.c -o lesson
./lesson
```

## Expected output

```text
Next: Arrays
Next: Pointers
Completed: 1/3; remaining: 50 minutes
```

## Practice

Try a different sample, predict the output, then compile again.
