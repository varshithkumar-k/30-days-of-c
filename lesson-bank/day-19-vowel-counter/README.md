# Day 19: Vowel Counter

Scan a null-terminated string and match vowels.

This example uses fixed sample data. Change the values to practice.

## Run

```sh
gcc -std=c17 -Wall -Wextra -pedantic main.c -o lesson
./lesson
```

## Expected output

```text
Vowels: 7
```

## Practice

Try a different sample, predict the output, then compile again.
